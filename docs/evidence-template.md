# Evidence record template

- Control / gate:
- Owner:
- Environment:
- Exact deployment ID and reviewed Git SHA:
- Provider/account/project identifier (masked):
- Procedure version:
- Started/completed UTC:
- Input fixture and immutable digest:
- Expected result:
- Actual result:
- Raw evidence location and SHA-256:
- PII/secret redaction review:
- Independent reviewer:
- Pass / fail / deviation:
- Follow-up and expiry:

Never create a record for an exercise that did not occur. Screenshots without identity, timestamp, environment, and immutable digest are not sufficient evidence.
